# ``1.19.4 3.5`` - Bug Fix Update

A small bug fix update with some features to finalize the "Mini" Update. **This is last major update for the 1.19.4 version of CWSM.**

To see the list of GitHub issues that have been completed with this update, please check out [this link](https://github.com/nonamecrackers2/crackers-wither-storm-mod/milestone/3?closed=1).

## Backend Notes:

- CrackersLib has been bumped to [1.19.4-0.4](https://github.com/nonamecrackers2/crackerslib/releases/tag/1.20.1-0.4)

## For Resource Pack Developers:

 - We removed the eye crack in the ``wither_storm.png`` texture and replaced it with the non-cracked variant. The cracked eye texture is now an overlay located in ``wither_storm_hurt_overlay.png``. **Please update your ``wither_storm.png`` texture accordingly!**

## Added/Tweaked:

 - **Withered Symbiont**
   - The Withered Symbiont shulker bullet spell will now destroy blocks it comes into contact with when spiraling
   - Slightly more shulker bullets will now be spawned during the second bossfight phase
   - Added some randomness to the evoker fangs spell
     - Also now has a chance to spawn sickened illagers
   - The Withered Symbiont can now smash multiple times in a row
     - The explosion radius of the smash attack will also now increase during the second phase, indicated by flame particles
   - Significantly buffed and reworked the arrows spell. The Symbiont will now spawn and throw arrows in a very chaotic manner, making them unpredictable and hard to dodge
   - The pulse spell will no longer affect symbionts, wither storms, wither storm heads, tentacles, or command blocks
   - Added an armor layer to the Withered Symbiont, allowing any armor it might be wearing to appear
   - The Symbiont now uses a weighted list for mob spawning, including a separate list for phase two of the bossfight
 - **New Sickened Mobs**
   - Added the sickened snow golem
 - The phasometer and amulet now have their upgraded variants available in the creative menu
 - New CWSM programmer art resource pack icon by McFella
 - Items will now be absorbed in a spiral-like motion
 - Buffed awareness radius on most sickened mobs
 - The Wither Storm will now target “natural” blocks such as grass, flowers, and leaves much more often. These blocks, however, will not impact the Wither Storm's consumed entity count
 - Removed some unnecessary vanilla code in both block clusters and the Wither Storm to improve performance
 - Optimized some code related to jukebox searching and non-targetable regions
 - 1x1 block clusters will no longer delete items to help prevent lag
 - Re-added fire as a block that can be picked up
 - Tractor beams can now remove water
 - Added a config option to enable falling block to cluster conversion, as it has been defaulted to off due to lag issues
 - The radius for items to be picked up by the Wither Storm during its hunchback phases increases as it consumes more mass
 - Added a config option for the Wither Storm to heal itself with a mob’s health if it chomps them
 - The Eye Of The Storm no longer shares the same enchantability as the golden command block tools
 - Sickened skeletons will now only shoot wither arrows 25% of the time
 - Sickened cats no longer crouch
 - Sickened wolves and parrots now move slightly faster
 - Sickened animals can now sprint towards their targets
 - Sickened zombies, wolves, and bees now alert each other
 - Bigger block clusters will no longer fall during the final bowels fight, as they were causing too much obstruction in the arena
 - The Wither Storm will no longer target fish and squid during its hunchback phases
 - Sickened animals are now faster when spawned in the bowels, instead of being super slow
 - The command block now spawns mobs inside of the bowels passively
 - Wither Storm heads now shoot wither skulls after being injured
 - Added block breaking sounds to small block clusters
 - Block clusters can now be ripped out of walls
 - Updated textures
   - Sickened iron golem + cracked layer texture
   - Sickened wolf
   - Sickened mooshroom
   - Sickened villager
   - Removed the eye crack in the ``wither_storm.png`` texture and replaced it with the non-cracked variant. The cracked eye texture is now an overlay located in ``wither_storm_hurt_overlay.png``
 - Updated languages:
   - zh_cn by junshengxie
