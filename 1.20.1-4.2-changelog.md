# ``1.20.1 4.2`` - Bug Fix Update

A small bug fix update with some features to finalize the "Mini" Update. 

**This changelog continues beyond what is written here, please see below for the continued changelog.**

## Backend Notes:

- CrackersLib has been bumped to [1.20.1-0.4.1](https://github.com/nonamecrackers2/crackerslib/releases/tag/1.20.1-0.4.1)

## For Resource Pack Developers:

 - We removed the eye crack in the ``wither_storm.png`` texture and replaced it with the non-cracked variant. The cracked eye texture is now an overlay located in ``wither_storm_hurt_overlay.png``. **Please update your ``wither_storm.png`` texture accordingly!**

## Added/Tweaked:

 - Changed the wither beacon summoning icon in JEI to use an isometric render of Reuben instead of a normal pig
 - The wither sickness overlay will no longer disable better UV support if Embeddium is installed
 - Formidibombs now have particle effects when placed and a cool particle animation when ignited
 - Made item rarities more consistent
 - Formidibombs now cause screen shake when exploding
 - Rebalanced bowels loot
   - You can no longer find Golden Apple Stew in the bowels, instead you can find all the ingredients to make it
   - Made the following rarer in general since they were clogging the loot table
     - Coal, Iron + Gold Ingots, Emeralds, Statues, Obsidian, Glow Berries, Redstone, Melon Seeds, Name Tag
   - New misc items
     - Slime Balls, Golden Carrots, Pumpkin Seeds
   - New treasure items (all enchanted)
     - Diamond Shovel, Iron Helmet, Diamond Chestplate, Diamond Leggings, Iron Boots, Iron Hoe, Iron Pickaxe
   - Adjusted misc items
     - Golden apples: Instead of just being a singular apple, they can have a chance to spawn with 1 to 3 of them
     - Arrows are slightly rarer but contain more arrows (8-16) instead of 4-8
   - Adjusted treasures (better enchants)
     - Golden Sword, Bow, Fishing Rod, Crossbow
   - Removed items
     - Rotten Flesh, Stone Axe
 - Added stripped tainted logs and wood
 - Added better and more bowels tremble sound effects
 - Rearranged the creative mode tab
 - Block clusters can now be better grabbed from walls
 - The amount of block clusters that fall from ceilings during cave rumbles has been lowered
 - Small slimes now get pulled into the Wither Storm automatically in a tornado-like pattern, like block clusters
 - Updated textures
   - Tainted dirt
   - Increased the brightness of flesh blocks to better match the Wither Storm’s texture
   - Brought back the animated texture for hardened flesh blocks

## Bug Fixes:

 - Fixed an issue where the golden apple stew could not be consumed by carnivores from the Origins mod [#1893](https://github.com/nonamecrackers2/crackers-wither-storm-mod/issues/1893)
 - Fixed a fatal crash when using versions of ModernFix below 5.18.0+mc1.20.1 [1888](https://github.com/nonamecrackers2/crackers-wither-storm-mod/issues/1888)
